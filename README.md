🚀 Projeto principal: AeChefia

Sistema de gestão para bares e restaurantes, em produção com clientes pagantes. Plataforma web responsiva, sem instalação. Sou responsável por toda a parte técnica: app, API, banco de dados e deploy.

📸 Cardápio por foto com IA: o restaurante envia a foto do cardápio e a IA lê seções, itens e preços. O resultado é validado no backend e fica para o dono revisar antes de salvar.
📋 Cardápio digital: categorias, preços e promoções atualizados em tempo real.
🪑 Gestão de mesas: status de cada mesa ao vivo (livre, ocupada, fechando).
🧾 Comandas digitais: abrir, editar e fechar comandas sem papel.
👨‍🍳 Cozinha em tempo real: fila de pedidos para cozinha e bar, com tempo por prato e impressão de etiquetas.
💰 Caixa e relatórios: controle de caixa com relatórios diários, semanais e mensais.
🏢 Multi-restaurante: cada estabelecimento acessa apenas os próprios dados.

Stack: React Native (Expo) · Next.js · TypeScript · Prisma · SQL · LLMs
